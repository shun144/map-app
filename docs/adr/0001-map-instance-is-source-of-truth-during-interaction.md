# 操作中のビューポートは地図インスタンスを正とする

ドラッグ・ズーム中のビューポートは地図インスタンスが保持し、TanStack Query のキャッシュと IndexedDB へは移動終了（`moveend`）時にデバウンスして書き込む。キャッシュから地図への反映は、初期表示と明示的な移動操作（「この位置へ移動」など）に限る。

キャッシュを正とする制御コンポーネント方式も検討したが、毎フレーム React の再レンダリングが発生し、地図→キャッシュ→地図の更新ループも起こりやすいため採用しなかった。

## Consequences

- キャッシュ上のビューポートは「最後に確定した値」であり、操作中の値とは一致しない。リアルタイムの値が必要な処理は MapController から取得する。
- キャッシュの更新を地図へ反映する購読は作らない。反映すると自分が書いた値で地図を動かすループになる。
- レイヤー（ベースマップ・オーバーレイ表示設定）は逆向きで、キャッシュを正とし、変化を差分で MapController に反映する。レイヤーは React の UI からしか変わらないため。同期の向きがビューポートと非対称なのは意図的である。
